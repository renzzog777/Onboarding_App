Press keys across the keyboard. Each key you press will light up below. You don't need to test every single key (e.g. media keys) - test what's relevant, then continue.

If F1–F12 don't light up: on most Macs these keys default to system shortcuts (brightness, volume, Mission Control) instead of sending a plain function-key press. Hold Fn while pressing them, or ask the advisor to check System Settings → Keyboard → "Use F1, F2, etc. keys as standard function keys". This is a macOS setting, not a bug in this page - the key press never reaches the browser at all until that's addressed.
